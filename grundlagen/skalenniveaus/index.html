Skalenniveaus: Was darf ich rechnen?

Dr. Jens Hüsers · Forschungsmethodik

Vier Stufen, jede baut auf der vorigen auf und erlaubt eine Rechenoperation mehr. Erst allgemein, dann am Kniegelenk und an Hop-Tests nach Kreuzbandplastik.

Teilen darf man nur, wenn die Null „nichts“ bedeutet.

Was ist erlaubt?

Jede Stufe erbt alles von der vorigen. Höhere Stufen lassen sich immer herunterstufen (Alter in Jahren → Altersgruppen), aber nie umgekehrt.

Gelenkstellung
Gelenkstellung · Intervallskala

0° ist die gestreckte Neutralstellung. Das ist eine Vereinbarung, kein „nichts“: Die Werte laufen über die Null hinaus ins Negative, in die Überstreckung. Eine Stellung von −5° ist nicht „weniger als keine Beugung“, sondern einfach eine andere Stellung. Deshalb sind Differenzen sinnvoll, Verhältnisse nicht: „120° ist 24-mal so viel Beugung wie 5°“ ergibt keinen Sinn.

Bewegungsumfang · Verhältnisskala

Der Bewegungsumfang ist eine Differenz zweier Stellungen. Er kann nicht negativ werden, und 0° heißt tatsächlich „keine Bewegung“. Damit hat er eine echte Null, und Prozente sind erlaubt. Dasselbe gilt für die Seitendifferenz zwischen linkem und rechtem Knie.

Klinik A gegen Klinik B

Mittlerer Bewegungsumfang sechs Wochen nach Knie-TEP. Hier ist ein Prozentvergleich zulässig, weil es um den Bewegungsumfang geht und nicht um eine Gelenkstellung.

Limb Symmetry Index: Teilen mit echter Null

Nach einer Kreuzbandplastik springen Patientinnen und Patienten einbeinig so weit wie möglich. Der Limb Symmetry Index setzt das betroffene Bein ins Verhältnis zum gesunden: LSI = betroffen / gesund × 100. Das funktioniert, weil eine Sprungweite von 0 cm wirklich „kein Sprung“ bedeutet. Verschieben Sie die Null und beobachten Sie, was mit dem LSI passiert.

6-Meter Timed Hop

„21 Prozent schneller“? Eine kleine Falle

Beim Timed Hop wird die Zeit für 6 Meter auf einem Bein gemessen. Zeiten haben eine echte Null, Prozentaussagen sind also erlaubt. Aber welche?

Um wie viel Prozent ist das gesunde Bein schneller?

Sauber formuliert: „Das gesunde Bein braucht rund 21 % weniger Zeit.“ Oder: „Die Geschwindigkeit ist 27 % höher.“ Beides stimmt, gemeint ist aber nicht dasselbe. „Schneller“ allein ist mehrdeutig.

Exkurs: Darf man Zeiten logarithmieren?

Ja, sinnvoll ist das aber nur bei Verhältnisskalen und nur für Werte größer null. Der Grund: Eine Differenz von Logarithmen ist ein Verhältnis, log(a) − log(b) = log(a / b). Ohne echte Null hätte dieses Verhältnis keine Bedeutung.

Dass Zeiten oft rechtsschief verteilt sind, ist nur der Anlass, sie zu logarithmieren, nicht die Begründung. Nebenbei löst der Logarithmus die Falle oben:

Teilen darf man nur, wenn die Null „nichts“ bedeutet.

Prüffrage für jede Variable: Kann der Wert negativ werden oder ist die Null nur vereinbart? Dann höchstens Differenzen. Bedeutet 0 „nichts davon“? Dann auch Verhältnisse und Prozente.
